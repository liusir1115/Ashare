# 盘后 Demo 搭建清单（第一阶段）

## 1. 当前目标

先做一个本地可跑的盘后 demo，验证最小闭环：

1. 自动生成市场总复盘
2. 手动录入持仓
3. 手动录入操作
4. 生成持仓复盘
5. 生成操作复盘
6. 页面展示结果
7. 导出 Markdown

## 2. 直接复用现有项目

当前项目已经有：

- Flask 后端
- 前端单页壳
- 基础数据接口
- 导出与结果保存基础

所以盘后 demo 不需要重做项目结构，只需要在现有项目上扩展一个新模式。

## 3. 第一阶段实现顺序

### Step 1：加盘后页面骨架

- 首页工作台保留
- 新增盘后复盘页
- 页面风格与盘前保持统一

### Step 2：先打通市场总复盘

- 后端新增盘后市场复盘接口
- 先用真实市场数据生成结构化中间结果
- 再接大模型生成正式报告

### Step 3：加持仓录入与持仓复盘

- 增加持仓表单
- 增加持仓复盘接口
- 输出组合总评 + 个股逐条分析

### Step 4：加操作录入与操作复盘

- 增加操作表单
- 增加操作复盘接口
- 输出整体操作复盘 + 单笔操作评价

### Step 5：加 Markdown 导出

- 将市场复盘、持仓复盘、操作复盘合并导出

## 4. 这一阶段先不做

- 券商自动同步
- 多用户体系
- 历史复盘中心
- 公网部署
- 小程序
- 实时盘中复盘

## 5. 下一步直接开做的任务

下一步建议直接进入开发，顺序是：

1. 梳理现有前端页面结构并拆出盘后模式入口
2. 设计盘后接口返回 JSON 结构
3. 先把“市场总复盘”做成可跑版本
4. 再补持仓和操作两个输入区
