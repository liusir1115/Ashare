# 第二轮排序规则说明

## 文档定位

本文档用于说明 AI 智能选股工具在第二轮情绪排序阶段的目标、输入输出、打分维度、权重原则、解释规范和异常处理策略。

它回答：

- 第二轮排序的职责是什么
- 第二轮使用哪些输入数据
- 排名和分数如何产生
- 盘前和盘后为什么可以采用不同倾向
- AI 应如何解释排序结果
- 哪些能力暂不纳入首版

## 第二轮排序目标

第二轮排序模块的目标不是再次执行硬性筛选，而是对第一轮候选股票池进行更贴近当前市场环境的优先级判断。

它重点解决以下问题：

- 哪些股票更符合当前热点和市场催化
- 哪些股票更匹配当前市场风格
- 哪些股票虽然满足第一轮量化条件，但情绪面支持不足
- 为什么某只股票应该排在本次结果的前列

## 排序输入

第二轮排序的输入包括：

- 第一轮候选股票池
- 第一轮命中条件明细
- 新闻催化信息
- 板块热度
- 资金流向
- 市场情绪
- 风格切换信号
- 龙头带动情况
- 涨停 / 连板结构
- 题材扩散度

首版可选增强输入包括：

- 个股热度
- 龙虎榜 / 机构游资参与度

## 排序输出

第二轮排序输出包括：

- 排名
- `100 分制` 分数
- 优先级标签
- 每只股票的排序解释
- 风格匹配说明
- 风险提示

优先级标签采用：

- `高优先级`
- `中优先级`
- `低优先级`

## 打分结构

第二轮采用分层打分，而不是将所有维度简单平铺。

首版打分结构包括：

1. `题材与催化层`
   - 新闻催化
   - 板块热度
   - 题材扩散度

2. `资金与情绪层`
   - 资金流向
   - 市场情绪
   - 风格切换

3. `市场地位层`
   - 龙头带动
   - 涨停 / 连板结构

4. `增强参考层`
   - 个股热度
   - 龙虎榜 / 游资机构参与度

设计原则如下：

- 分层打分优于简单平铺打分
- `增强参考层` 不作为首版主决定项
- `增强参考层` 主要作为加分项或解释增强项使用

## 权重原则

首版不写死每个维度的具体数值权重，而采用 `权重区间与优先级原则`。

原因如下：

- 首版数据源和口径仍需在真实运行中验证
- 过早写死精确权重，后续调整成本过高
- 完全不定义权重层级会导致开发和解释失去一致性

因此，权重表达采用以下形式：

- `高权重`
- `中权重`
- `低权重 / 加分项`

## 盘前与盘后权重倾向

盘前与盘后共用同一排序框架，但权重倾向允许不同。

### 盘前模式

盘前模式更偏向预期判断，因此以下维度应给予更高权重：

- 新闻催化
- 板块热度
- 题材扩散度

盘前模式中等权重维度包括：

- 资金流向
- 龙头带动
- 市场情绪

盘前模式低权重或加分项包括：

- 龙虎榜 / 游资机构参与度
- 个股热度

### 盘后模式

盘后模式更偏向复盘判断，因此以下维度应给予更高权重：

- 资金流向
- 市场情绪
- 风格切换
- 涨停 / 连板结构

盘后模式中等权重维度包括：

- 板块热度
- 龙头带动
- 题材扩散度

盘后模式低权重或加分项包括：

- 个股热度
- 龙虎榜 / 游资机构参与度

## AI 解释规范

AI 解释必须服务于结果理解，而不是生成冗长评论。

首版解释要求如下：

- 风格以精简为主
- 每只股票的解释应采用固定结构
- 解释内容应优先说明排序原因，而不是泛泛描述个股背景

默认解释结构包括：

1. `排序原因`
   - 为什么该股票排在这个位置

2. `风格匹配`
   - 它与当前市场风格的契合点是什么

3. `催化与题材`
   - 当前热点、消息或板块联动体现在哪里

4. `风险提示`
   - 当前最大的短板、不确定性或观察点是什么

盘前与盘后允许采用不同解释模板，但都应遵循：

- 语言简洁
- 逻辑一致
- 能对排名负责

## 分数与标签映射原则

首版保留分数与标签并存的形式。

设计目标包括：

- 分数用于提供排序细粒度
- 标签用于帮助用户快速理解优先级

当前仅规定保留标签体系，不在首版文档中写死具体分段阈值。

具体阈值可以在开发和真实运行验证后再确定。

## 异常与降级处理

第二轮排序必须与数据可用性约束联动。

正式要求如下：

- 核心维度缺失时，不允许生成正式排序结果
- 非核心增强维度缺失时，允许降级运行
- 降级运行时必须在结果中提示缺失维度
- AI 解释不得假装引用不存在的数据

## 首版后置项

以下能力不作为 v0.1 排序主规则的一部分：

- 不推荐理由
- AI 自由长篇点评
- 个性化权重偏好
- 用户自定义排序公式

## 后续扩展位

以下方向保留为后续扩展：

- 更细粒度的权重配置
- 个股热度与龙虎榜深度整合
- 更稳定的结构化新闻催化评分
- 基于历史表现的权重回溯校准
