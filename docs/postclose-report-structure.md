# 盘后复盘报告结构说明

## 文档定位

本文档用于定义盘后模式的报告结构，包括：

- 市场总复盘结构
- 持仓复盘结构
- 操作复盘结构
- 首页摘要结构

它回答：

- 报告要分几部分
- 每一部分最少要包含哪些章节
- 每一章应该放哪些结论和证据
- 如何让报告既稳定又适合 LLM 生成

## 报告总体结构

一次完整的盘后复盘会话由三份结构化结果组成：

1. `市场总复盘报告`
2. `持仓复盘报告`
3. `操作复盘报告`

展示层面分成两级：

- `首页摘要层`
- `完整报告层`

## 一、首页摘要结构

首页工作台只展示摘要，不展示全文。

首页摘要包括：

1. `今日复盘状态`
   - 今日市场复盘是否已生成
   - 持仓是否已录入
   - 操作是否已录入
   - 是否已生成完整盘后复盘

2. `市场复盘摘要`
   - 一句话总收口
   - 今日主线
   - 今日次主线
   - 风险边界
   - 次日重点

3. `个人复盘进度`
   - 持仓录入状态
   - 操作录入状态
   - 持仓复盘生成状态
   - 操作复盘生成状态

4. `持仓摘要`
   - 当前录入持仓数量
   - 整体持仓评价摘要
   - 重点风险持仓数量或提示

5. `操作摘要`
   - 当前录入操作数量
   - 整体操作评价摘要
   - 典型问题操作提示

6. `快捷操作入口`
   - 查看市场总复盘
   - 录入持仓
   - 录入操作
   - 生成完整复盘
   - 导出 Markdown

7. `次日执行建议摘要`
   - 顺着看摘要
   - 回避方向摘要

## 二、市场总复盘报告结构

市场总复盘报告为盘后模式核心，采用 8 章结构。

### 1. 一句话总收口

目标：

- 用极短文字概括今天市场的本质

要求：

- 仅 `1 到 3 句话`
- 必须回答今天市场是：
  - 修复
  - 分歧
  - 切换
  - 退潮
  - 缩容
  - 混沌
  中的哪一种或哪种组合

### 2. 盘型 / 环境

至少包括：

- 指数表现
- 涨跌家数
- 成交额 / 量能变化
- 资金净流入净流出
- 涨停家数
- 封板率
- 连板高度
- 炸板家数
- 跌停家数
- 盘型判断

目标：

- 用客观数据先定义今天是什么盘

### 3. 资金流证据

至少包括：

1. 行业 / 板块净流入
2. 行业 / 板块净流出
3. 个股净流入代表
4. 个股净流出代表
5. `资金方向裁定`

说明：

- `资金方向裁定` 是核心结论层
- 可以采用固定色块或固定样式强调

### 4. 主线 / 次主线 / 风险边界 / 次日重点

采用顶部四卡结构：

- 今日主线
- 今日次主线
- 风险边界
- 次日重点

每张卡至少包括：

- 名称
- 一句话结论
- 代表方向或代表股（可选）

### 5. 主线与轮动拆解

按方向拆解市场结构，建议覆盖：

- 主线
- 次主线
- 活口
- 轮动方向
- 失败方向

每个方向至少包括：

- 代表股
- 板块逻辑
- 裁定结论

说明：

- `活口` 概念保留

### 6. 市场情绪与连板结构

至少包括：

- 涨停总数
- 连板高度
- 高位 / 中位 / 低位承接
- 炸板 / 回封情况
- 情绪锚个股
- 情绪阶段判断

情绪阶段采用两套表达并存：

- `强 / 中 / 弱`
- `修复 / 分歧 / 退潮 / 混沌`

### 7. 原因拆解

形式采用：

- `问答式短段落`

建议回答 `3 到 5 个为什么`，例如：

- 为什么这条线是主线
- 为什么那条线只是次主线
- 为什么某方向不能追
- 为什么某方向只是活口
- 为什么今天风险边界在这里

### 8. 次日执行卡

固定成 4 部分：

1. 顺着看
2. 只观察
3. 回避
4. 次日验证条件

要求：

- `顺着看` 必须尽量具体到 `方向 + 候选股票`
- 表达简短但要可执行

## 三、持仓复盘报告结构

持仓复盘用于回答：用户当前持仓放在今天这个市场里，到底合不合理。

### A. 整体持仓评价

放在持仓报告最前面，至少包括：

- 当前持仓是否匹配市场主线
- 当前持仓是否过于分散
- 当前持仓是否偏防守或偏进攻
- 当前持仓整体风险评价
- 明日整体持仓关注点

### B. 每只持仓分析

每只持仓统一输出 5 个区块：

1. `持仓定位`
   - 主线 / 次主线 / 活口 / 轮动 / 风险边界中的哪类

2. `市场匹配度`
   - 是否匹配今天的主线与市场风格

3. `当前状态判断`
   - 继续观察、继续持有、谨慎、接近失效等条件式判断

4. `风险点`
   - 当前最大风险是什么

5. `次日关注点`
   - 明天需要看什么条件来决定是否继续拿

### C. 持仓标签体系

每只持仓保留以下标签之一：

- `顺势持仓`
- `观察持仓`
- `偏弱持仓`
- `风险持仓`

### D. 空持仓情况

允许空持仓。

空持仓时输出：

- 今日空仓是否合理
- 空仓在当前市场环境下是否属于正确选择

## 四、操作复盘报告结构

操作复盘用于回答：用户今天的交易动作到底做得对不对。

### A. 整体操作评价

放在操作报告最前面，至少包括：

- 今日整体执行是否稳定
- 是否有过度交易
- 是否有明显偏离主线
- 是否买卖节奏有问题
- 是否风险控制不到位

### B. 每笔操作分析

每笔操作统一输出 5 个区块：

1. `环境匹配度`
   - 这笔操作是否符合当天市场环境与主线结构

2. `时机判断`
   - 买点 / 卖点是否合适
   - 是否存在过早、过晚、追高、卖飞等问题

3. `执行一致性`
   - 是否符合用户自己的交易计划与操作理由

4. `问题归因`
   - 这笔操作最主要的问题是什么

5. `改进建议`
   - 下次遇到类似情况应如何改进

### C. 操作录入字段要求

首版要求完整记录后才能生成正式操作复盘：

- 股票代码 / 名称
- 买入 / 卖出方向
- 成交价
- 仓位变化
- 操作时间
- 操作理由
- 操作预期（可选）
- 结果评价自述

### D. 无操作日

允许无操作。

无操作时输出：

- 今日无操作是否合理
- 在当前市场环境下，不出手是否属于正确选择

## 五、报告统一写法要求

市场、持仓、操作三类报告统一要求：

1. 结构固定
2. 结论优先
3. 证据后置
4. 语言精简
5. 不写长篇空话
6. 不把不存在的数据写成事实
7. 必须区分“事实层”和“解释层”

## 六、导出结构

首版支持：

- 页面完整展示
- Markdown 导出

Markdown 导出应包含：

- 市场总复盘完整结构
- 持仓复盘完整结构
- 操作复盘完整结构
- 交易日与数据来源说明
