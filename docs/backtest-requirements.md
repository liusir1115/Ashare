# 回测模块需求文档

## 1. 文档定位

本文档仅用于定义 `回测模块（Backtest Module）` 的正式需求边界。

本模块独立于：
- 盘前选股模块
- 盘后复盘模块

但允许复用同一套：
- 数据源
- LLM 基础设施
- Web 系统
- 部署环境
- 结果保存能力

本模块的目标不是给出“今天该买什么”，而是回答：
- 某个策略过去是否有效
- 策略在哪些市场环境中更有效
- 策略收益、回撤、胜率、换手等表现如何

## 2. 模块目标

回测模块首版目标如下：

1. 允许用户针对一套结构化选股策略执行历史回测
2. 基于真实历史日线数据验证策略表现
3. 输出可读、可比较、可解释的历史表现结果
4. 为后续盘前策略优化提供历史依据
5. 为后续接入 LLM 策略生成与解释能力预留接口

## 3. 用户与使用场景

当前正式用户包括：
- `primary_user`
  产品主使用者，具备一定交易经验，希望验证策略长期表现
- `friend_user`
  小范围朋友用户，希望比较不同选股思路的历史表现

当前典型使用场景包括：

1. 用户输入一套技术面选股条件，查看过去 3 年回测表现
2. 用户比较同一策略在不同持有周期下的表现差异
3. 用户比较“前 5 / 前 10 / 前 20”选股数量的表现差异
4. 用户验证某类策略是否在特定年份或市场阶段有效
5. 用户基于回测结果继续优化策略参数

## 4. 与其他模块的关系

回测模块是第三个独立模块，不从属于盘前或盘后。

边界如下：

- 盘前模块
  负责当天或最近交易日的选股输出

- 盘后模块
  负责市场复盘、持仓复盘、操作复盘与问答

- 回测模块
  负责历史策略验证，不承担盘前推荐或盘后解释职责

共享关系如下：

- 可复用盘前的结构化筛选条件体系
- 可复用统一的 Tushare 数据基础设施
- 可复用统一的 LLM 配置
- 可复用统一的前端账户体系与结果保存体系

## 5. 当前正式范围

回测模块首版正式支持以下范围：

- 日线级别回测
- A 股股票池历史选股回测
- 技术面策略回测
- 长历史区间回测
- 复权价格处理
- 交易成本模型
- 可交易约束模型
- 回测结果图表展示
- 回测结果保存
- 回测结果导出

## 6. 当前不做什么

回测模块首版明确不包含以下能力：

- 分钟级回测
- Tick 级撮合模拟
- 盘中实时回测
- 券商级精细成交回放
- 新闻面历史回测
- 情绪面历史回测
- 强化学习式自动训练
- 自动穷举海量参数组合
- 自动生成实盘交易指令

## 7. 数据源要求

回测模块首版以 `Tushare` 为主数据源。

首版需要的核心数据类型包括：

- `trade_cal`
  交易日历
- `stock_basic`
  股票基础信息
- `daily`
  历史日线行情
- `daily_basic`
  历史换手率、市值、量比等基础因子
- `cyq_perf`
  筹码结构相关字段

数据源要求如下：

1. 历史数据长度不受盘前模块默认 `70` 日限制
2. 首版默认支持 `1年 / 3年 / 5年` 历史区间
3. 默认回测区间为 `3年`
4. 所有回测必须标明：
   - 数据源
   - 回测区间
   - 复权方式
   - 成本参数
   - 可交易约束

## 8. 输入方式

回测模块首版输入以结构化策略条件为主。

首版输入项包括：

1. 回测时间区间
   - 可选：`1年 / 3年 / 5年`
   - 默认：`3年`

2. 股票范围
   - 沪深主板
   - 沪深主板 + 创业板
   - 科创板

3. 排除项
   - ST / *ST
   - 停牌
   - 新股
   - 北交所

4. 策略条件
   沿用盘前模块中的结构化技术指标体系，包括但不限于：
   - 股价区间
   - 总市值 / 流通市值
   - 涨跌幅区间
   - 近 N 日涨幅
   - 近 N 日回撤
   - 换手率
   - 成交额
   - 量比
   - 振幅
   - 均线位置
   - 均线突破
   - N 日新高 / 新低
   - 连续涨跌天数
   - 持续放量 / 缩量
   - 筹码集中度
   - 获利盘比例
   - 价格偏离筹码

5. 交易制度参数
   - 选股数量：`前5 / 前10 / 前20`
   - 默认：`前10`
   - 买入时点：默认 `T日收盘选股，T+1开盘买入`
   - 持有周期：`1天 / 3天 / 5天`
   - 默认：`3天`

## 9. 回测执行逻辑

回测模块首版采用日线级固定制度回测。

默认逻辑如下：

1. 在每个可回测交易日收盘后，根据策略条件筛选股票池
2. 从股票池中选取排名前 `N` 的股票
3. 在下一交易日开盘价买入
4. 按设定持有周期持有
5. 到期后按规则卖出
6. 汇总所有交易结果，输出历史统计表现

首版默认采用：
- 等权持仓
- 固定持有周期
- 统一成本模型

后续可扩展：
- 止盈 / 止损规则
- 分批调仓
- 不同权重分配方式
- 多策略对比

## 10. 复权价格要求

复权价格首版必须支持。

首版要求如下：

- 默认采用 `前复权`
- 可预留：
  - 不复权
  - 后复权

原因如下：

1. 不复权会导致长期收益失真
2. 回测模块必须以更接近真实历史价格序列的方式运行

## 11. 交易成本模型

首版必须包含简化版交易成本模型。

默认参数如下：

- 买入手续费：万 3
- 卖出手续费：万 3
- 印花税：仅卖出收取
- 滑点：万 5

要求如下：

1. 成本参数必须展示在回测结果页
2. 成本参数必须写入回测结果保存记录
3. 成本参数后续允许用户调整

## 12. 可交易约束

首版必须规则化处理可交易约束。

默认规则如下：

- 一字板不买
- 跌停不卖
- 停牌不做
- ST / *ST 不做
- 新股不做

要求如下：

1. 所有约束作为系统默认规则存在
2. 所有约束在结果页明确展示
3. 首版无需做更复杂的撮合模拟

## 13. 输出结果

回测模块首版至少输出以下结果：

### 13.1 指标结果

- 累计收益率
- 年化收益率
- 最大回撤
- 胜率
- 盈亏比
- 交易次数
- 平均持有天数

### 13.2 图表结果

首版默认输出以下图表：

- 累计收益曲线
- 回撤曲线
- 年度收益统计图
- 核心指标摘要卡

### 13.3 结果说明

首版结果页必须明确展示：

- 回测策略摘要
- 回测区间
- 股票范围
- 复权方式
- 成本参数
- 可交易约束

## 14. 结果保存与导出

回测模块首版支持：

- 保存单次回测结果
- 回看历史回测记录
- 导出结构化结果

导出格式首版建议支持：

- Markdown
- Excel

## 15. LLM 在回测模块中的角色

回测模块允许接入大模型，但首版不依赖 LLM 才能运行。

首版允许 LLM 参与以下环节：

1. 策略解释
   - 将结构化策略转成自然语言说明

2. 结果总结
   - 总结某策略在哪些年份或环境下更有效

3. 参数优化建议
   - 基于已有回测结果提出候选优化方向

首版不允许 LLM 直接替代：

- 历史数据拉取
- 收益计算
- 回撤计算
- 成本计算
- 交易执行模拟

原则如下：

- 程序负责计算
- LLM 负责解释

## 16. 页面结构建议

回测模块建议单独成为一个正式页面或模块入口。

首版建议页面结构如下：

1. 回测工作台
   - 输入策略
   - 设定回测参数
   - 执行回测

2. 回测结果页
   - 指标摘要
   - 收益图表
   - 年度表现
   - 参数与规则说明

3. 历史回测页
   - 查看过去回测记录
   - 重新打开某次回测结果

## 17. 当前业务约束

回测模块首版必须遵守以下约束：

1. 只做日线级别
2. 只做技术面回测
3. 所有回测基于真实历史数据
4. 禁止用演示数据伪造回测结果
5. 所有关键参数必须可追溯
6. 所有图表和结果必须基于程序真实计算

## 18. 与后续版本的关系

回测模块后续可扩展方向包括：

- 新闻面历史回测
- 情绪面历史回测
- 策略自然语言生成
- 策略参数对比实验
- 多策略组合回测
- 更复杂的止盈止损制度
- 更精细的成交约束模拟

但这些均不属于首版正式范围。

## 19. 当前结论

回测模块首版应被定义为：

一个独立于盘前、盘后的日线级技术策略验证模块。

它首版的核心是：

- 长历史
- 前复权
- 成本模型
- 可交易约束
- 结构化结果输出

而不是一开始就追求：

- 情绪历史回测
- 新闻历史回测
- 自动化调参
- 高频级别模拟
