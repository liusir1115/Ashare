# 功能模块说明

## 文档定位

本文档用于从产品结构层面说明 AI 智能选股工具的页面组成、核心功能模块、用户主流程和关键交互节点。

它回答：

- 产品由哪些页面组成
- 每个页面负责什么功能
- 用户如何完成一次盘前或盘后选股
- 页面之间如何流转
- 首版哪些模块必须实现，哪些可以后置

## 产品功能总览

当前产品是一个面向 A 股盘前/盘后场景的智能选股 Web 工具，整体由以下功能构成：

- 账号登录与访问控制
- 首页工作台
- 第一轮技术选股配置
- 第二轮情绪排序结果查看
- 个股详情分析
- 历史结果查看
- 结果导出与共享
- 后台管理能力

## 页面结构概览

首版页面结构包括：

1. `登录页`
2. `首页 / 工作台`
3. `选股配置页`
4. `选股结果页`
5. `个股详情侧栏 / 弹窗`
6. `历史结果页`
7. `管理页`

说明如下：

- 首页即工作台，不单独设置纯入口页
- 选股配置页与结果页分开设计，避免单页复杂度过高
- 个股详情优先采用结果页内展开侧栏或弹窗的方式，不额外跳转独立页面
- 历史结果页同时支持查看单次选股任务和按日期归档结果
- 管理页暂定为轻量后台，仅服务于小范围共享场景下的账号管理与基础系统配置

## 首页 / 工作台

首页直接作为用户工作台，承担日常使用的统一入口。

首版优先功能包括：

- 今日模式切换
  - 盘前
  - 盘后
- 快速开始卡片
  - 进入选股配置
  - 查看最近一次结果
- 今日市场简报
  - 新闻摘要
  - 热点板块
  - 市场风格判断
- 系统状态
  - 数据源状态
  - 最近更新时间

可后置功能包括：

- 最近一次选股摘要
- 历史快捷入口

## 选股配置页

该页面负责组织第一轮技术选股所需的全部输入条件。

页面结构包括：

1. `模式区`
   - 盘前 / 盘后
   - 股票范围
   - 排除项
2. `第一轮筛选区`
   - 指标条件选择
   - 区间输入
   - 条件列表
3. `策略优化区`
   - 条件过严 / 过宽提示
   - 调整建议
4. `执行区`
   - 开始筛选
   - 重置条件
   - 查看上一次配置

交互要求如下：

- 筛选条件采用类似条件拼接式的组织方式
- 条件项按需添加，不一次性展开全部指标
- 首版不支持条件拖动排序
- 选股配置页采用左侧条件、右侧辅助信息的布局

## 选股结果页

该页面负责展示第二轮排序后的最终结果。

页面结构建议分为两层：

1. `顶部摘要区`
   - 盘前 / 盘后模式
   - 股票范围
   - 条件摘要
   - 第一轮命中数
   - 第二轮最终展示数
2. `结果列表区`
   - 排名
   - 分数
   - 股票名称 / 代码
   - 所属行业 / 概念
   - 第一轮入选摘要
   - 第二轮核心理由
   - 风险点
   - 查看详情

结果列表采用：

- 表格主视图
- 支持展开查看摘要详情
- 支持打开个股详情侧栏 / 弹窗

首版默认展示：

- 第一轮筛选命中总数
- 第二轮最终展示数
- 数据缺失提示

可后置展示项包括：

- 任务运行时间
- 数据更新时间
- 更细粒度的评分维度明细

## 个股详情展示

个股详情优先采用结果页内侧栏或弹窗展开。

详情内容至少包括：

- 基础信息
- 第一轮命中条件明细
- 第二轮排序解释
- 当前市场风格匹配点
- 当前催化因素
- 风险点

## 历史结果页

该页面负责查看已保存的选股结果。

首版目标包括：

- 按单次任务查看历史记录
- 按日期归档查看盘前 / 盘后结果
- 支持重新打开结果详情
- 支持导出历史结果

## 管理页

管理页的定位是轻量后台，不是复杂运营系统。

首版仅考虑以下能力：

- 管理员创建账号
- 白名单用户管理
- 基础系统配置
  - 数据源开关
  - 默认股票范围
  - 默认排除项
- 查看系统数据健康状态

如果后续确认首版不需要可视化管理，也可以退化为：

- 无独立管理页
- 仅保留后台配置文件或命令行管理方式

## 用户主流程

当前正式主流程如下：

1. 用户登录系统
2. 进入首页工作台
3. 选择盘前或盘后模式
4. 进入选股配置页设置第一轮条件
5. 系统执行第一轮硬筛
6. 若结果异常，系统提示用户优化条件
7. 系统执行第二轮情绪排序
8. 用户在结果页查看前 10 名及完整榜单
9. 用户展开个股详情，查看排序原因与风险点
10. 系统保存结果，供后续查询、导出和共享

## 关键交互节点

- 条件冲突提示
- 结果过多时的缩窄建议
- 结果过少或为 0 时的放宽建议
- 第二轮结果解释
- 数据缺失提示
- 历史记录回看与导出

## 后续扩展位

以下能力预留扩展接口，但不作为首版必做：

- 自然语言生成筛选条件
- 实时盘中监控
- 历史回测
- 多策略保存
- 分享链接
- 更复杂的用户权限体系
