# Version 1 前端展示版开发记录

## 版本定位

Version 1 是 AI 智能选股工具的第一版前端展示页面，目标是先跑通正式选股主链路的页面体验，不接入后端、不接入真实数据源、不实现登录。

本版本从工作台开始，聚焦用户完成一次盘前或盘后选股的核心流程：

1. 进入工作台查看市场概览与数据源状态。
2. 选择盘前或盘后模式。
3. 进入选股配置页面，设置第一轮技术硬筛条件。
4. 查看第二轮情绪排序后的结果表格。
5. 打开右侧详情抽屉，查看个股排序解释、风险与数据说明。

## 已确认设计方向

- 页面形态采用工具型仪表盘，不做营销型首页。
- 视觉风格采用轻量 SaaS + 金融工具信息密度。
- 暂时不需要登录页，后续再补账号与白名单访问。
- 当前只做前端，可使用虚拟数据，不需要在页面上专门标注“示例数据”。
- 选股配置页尽量覆盖需求文档提到的全部首版指标。
- 结果页采用主表格 + 右侧详情抽屉。
- 盘前与盘后需要有更细的差异化，不仅是模式标签：
  - 盘前更强调新闻催化、板块热度、题材扩散度和预期判断。
  - 盘后更强调资金流向、市场情绪、风格切换、涨停 / 连板结构和复盘判断。
- 前端需要展示数据源状态，包括正常、降级、数据不完整等状态。
- 导出功能暂时做成 Excel 和 Markdown 两个按钮即可。

## Version 1 包含内容

### 工作台

- 盘前 / 盘后模式切换。
- 快速开始入口。
- 今日市场简报。
- 热点板块与市场风格判断。
- 数据源状态与更新时间展示。
- 不同模式下展示不同的观察重点和文案。

### 选股配置

- 模式区：
  - 盘前 / 盘后。
  - 股票范围。
  - 默认排除项。
- 第一轮筛选区：
  - 股价区间。
  - 总市值区间。
  - 流通市值区间。
  - 涨跌幅区间。
  - 近 N 日涨幅区间。
  - 近 N 日回撤区间。
  - 换手率区间。
  - 成交额区间。
  - 成交量放大倍数。
  - 振幅区间。
  - 持续放量 / 缩量。
  - 均线位置。
  - 均线突破。
  - N 日新高 / N 日新低。
  - 连续上涨 / 连续下跌天数。
  - 筹码集中度。
  - 所属行业 / 概念。
  - 基础排除条件组合。
- 策略优化提示：
  - 条件过宽建议。
  - 条件过严建议。
  - 条件冲突提示。
  - 结果为 0 的优化方向。
- 执行区：
  - 开始筛选。
  - 重置条件。
  - 查看上一次配置。

### 结果页

- 顶部摘要：
  - 模式。
  - 股票范围。
  - 条件摘要。
  - 第一轮命中数。
  - 第二轮展示数。
  - 数据源、交易日、更新时间。
- 结果主表格：
  - 排名。
  - 分数。
  - 优先级标签。
  - 股票名称 / 代码。
  - 所属市场。
  - 所属行业 / 概念。
  - 第一轮命中摘要。
  - 第二轮核心理由。
  - 风险点。
  - 查看详情入口。
- 完整榜单入口。
- Excel / Markdown 导出按钮。

### 个股详情抽屉

- 基础信息。
- 第一轮命中条件明细。
- 第一轮关键指标。
- 第二轮排序解释。
- 风格匹配说明。
- 催化与题材说明。
- 风险提示。
- 第二轮评分摘要。
- 数据源、交易日、降级字段说明。

### 数据状态展示

- 数据源正常。
- 非核心数据缺失时降级运行。
- 核心数据缺失时数据不完整。
- 最近更新时间。
- AKShare / Baostock / 新闻源等状态展示。

## Version 1 不包含内容

- 登录页。
- 公开注册。
- 管理员账号创建。
- 白名单账号管理。
- 真实后端接口。
- AKShare / Baostock / Tushare 的真实接入。
- 真实选股计算。
- 真实导出文件生成。
- 自然语言生成筛选条件。
- 历史回测。
- 盘中实时监控。
- 分享链接。
- 多策略保存。
- 复杂权限体系。

## 下一版本建议

Version 2 建议进入以下方向：

1. 补充前端路由或轻量应用结构，拆分工作台、配置、结果、历史等页面。
2. 接入真实后端接口骨架，定义前后端数据契约。
3. 实现数据健康检查 API，并让前端状态来自真实接口。
4. 接入 AKShare 第一轮硬筛的基础数据链路。
5. 将结果页虚拟数据替换为真实任务结果。
6. 实现真实 Excel / Markdown 导出。
7. 增加历史结果页。
8. 再决定是否补登录、白名单账号和轻量管理页。
